# Dashboard Maker Rollout Scorecard

Record these measures per released request in the first 30 days.

| Metric | Definition | Target by month 3 |
|---|---|---|
| Time to dashboard | Request submission to production UAT | ≤4 working hours for repeat patterns |
| First-pass UAT | Releases accepted without semantic/visual rework | ≥80% |
| KPI reuse | Requested KPI references resolved from catalog | ≥60% |
| Rework rate | Releases needing KPI/source correction within 30 days | <15% |
| Query efficiency | Bytes and cost per dashboard refresh | 30% lower than baseline |
| Freshness reliability | Successful scheduled refreshes within SLA | ≥99% |
| Governance | Reports linked to a KPI version and curated source | 100% |

Review weekly during the pilot. Promote templates and marts only after measured reuse and cost justify their maintenance.
